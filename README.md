# Envex Energy — Website

Front-end for **Envex Energy**, a renewable energy (solar) startup. The design
originated as a Claude Design (claude.ai/design) handoff bundle and has since
been reorganised into the layout below.

## Folder structure

```
.
├── src/                  Working prototype — this is what you edit
│   ├── index.html        The landing page (HTML/CSS/JS, no build step)
│   └── support.js        Claude Design runtime (generated — do not edit)
├── public/media/         Assets the page actually loads (4 files)
├── design/               Design-tool sources, kept for reference
│   ├── Envex Energy Landing.dc.html   Canvas source
│   └── Envex Energy Landing.html      Self-contained export (~12MB)
├── docs/
│   └── envex-energy-phase-plan.md     Build roadmap, phases 1–3
└── raw/                  Unused source material (git-ignored, ~85MB)
    ├── frames/           Render frames and logo checks
    ├── media/            Hero video takes that didn't ship
    └── uploads/          Raw uploads, pasted images, references
```

## Running it

There is no build step. Open `src/index.html` directly in a browser — asset
paths are relative (`../public/media/...`), so it works from the file system.

## Live assets

Only four files in `public/media/` are referenced by the page:

| File | Used for |
| --- | --- |
| `envex-mark-light.png` | Nav bar logo mark |
| `envex-logo.png` | Footer logo |
| `hero-still.jpeg` | Hero section background |
| `v3-mid-clean.png` | CTA band background |

Everything else lives under `raw/` and ships nowhere. If you add an asset to the
page, move it into `public/media/` — `raw/` is git-ignored.

## Notes on the design sources

`design/` holds the original design-tool output. The prototypes are **not
production code** — they are visual specs. When implementing in a real framework
(React, Vue, etc.), match the visual output rather than copying the prototype's
internal structure. Dimensions, colors and layout rules are all spelled out in
the source; read the HTML and CSS rather than screenshotting.

`support.js` is generated by the Claude Design runtime and should not be edited
by hand.
